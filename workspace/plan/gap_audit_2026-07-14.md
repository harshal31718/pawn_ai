## D. Browser test findings (live)

### D-1 `[fixed — verify live]` Sidebar kebab menu turns translucent while open (user screenshot: garbled overlapping items)
User screenshot (project "suiiiii" → chat "New Chat" → kebab): dropdown items
rendered garbled/overlapping the rows beneath. Root cause: the kebab wrapper
divs use `opacity-0 group-hover:opacity-100 transition-opacity` — when the
pointer leaves the row (or hovers a *different* row's kebab) while the menu is
still open, the whole wrapper (including the OPEN menu, which is its child)
fades toward opacity 0, so the underlying sidebar rows bleed through the
"transparent" menu. Fixed: added `focus-within:opacity-100` to all three
wrappers (ProjectRow ×2 — project + in-project chat rows; Sidebar ×1 —
standalone chat rows): the kebab button keeps focus while its menu is open, so
an open menu now always renders fully opaque. Verify live in Chrome.
Note: `animate-in fade-in zoom-in-95` classes on the dropdown are dead (no
tailwind animate plugin installed) — harmless, but could be removed or the
plugin added if the entrance animation is actually wanted.
